# LightDM Greeter Ganapati - Project Instructions
_the Remover of Obstacles_

## Overview

A premium, graphical login manager/greeter rewritten in Go, designed to:
- Boots lightning-fast with minimal dependencies
- Run under both X11 and Wayland session selection
- Present a gorgeous, modern minimalist aesthetic
- Be static-binary compile safe for NixOS and standard systems

## Technology Stack

- **Language**: Go
- **UI Toolkit**: Gio (gioui.org) or other lightweight graphical toolkit
- **D-Bus Library**: `github.com/godbus/dbus/v5`
- **LSP Support**: `gopls`

## Code Organization

- **cmd/lightdm-elephant-greeter/** - Entrypoint for the greeter executable (see `cmd/lightdm-elephant-greeter/AGENTS.md`)
- **pkg/dbus/** - LightDM D-Bus protocol integration (see `pkg/dbus/AGENTS.md`)
- **pkg/ui/** - Graphics and UI layout handling (see `pkg/ui/AGENTS.md`)
