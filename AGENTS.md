# LightDM Greeter Ganapati - Project Instructions
_the Remover of Obstacles_

## Overview

A premium, graphical login manager/greeter rewritten in Go, designed to:
- Boots lightning-fast with minimal dependencies
- Run under both X11 and Wayland session selection
- Present a gorgeous, modern minimalist aesthetic
- Be static-binary compile safe for NixOS and standard systems

## Technology Stack

- **Language**: Go
- **UI Toolkit**: Gio (gioui.org) or other lightweight graphical toolkit
- **D-Bus Library**: `github.com/godbus/dbus/v5`
- **LSP Support**: `gopls`

## Code Organization

- **cmd/lightdm-greeter-ganapati/** - Entrypoint for the greeter executable (see `cmd/lightdm-greeter-ganapati/AGENTS.md`)
- **pkg/dbus/** - LightDM D-Bus protocol integration (see `pkg/dbus/AGENTS.md`)

### Architecture Summary
A dual-transport LightDM greeter: protocol-first pipe-FD integration (LightDM 1.31+) with legacy D-Bus fallback, decoupled Go D-Bus/protocol communications, and Gio GUI presentation loops, enabling isolated protocol testing and pure-Go graphics execution.

### Domain Language
- **Seat**: Represents physical input/output display workstation.
- **Session**: A desktop environment session (Wayland or X11) registered in standard directory paths.
- **Greeter**: The graphical login interface spawned by LightDM to prompt and authorize credentials.
- **Pipe protocol**: LightDM 1.31+ binary protocol over inherited FDs (`LIGHTDM_TO_SERVER_FD`/`LIGHTDM_FROM_SERVER_FD`); big-endian `[id][len][payload]` framing carrying PAM conversation messages.

### Conventions Summary
- Style: `gofmt` tabs formatting, explicit return-style error wrapping (`fmt.Errorf` `%w`), PascalCase package declarations, interface-based decoupling (no `I` prefix), conventional commits, protocol-first transport with D-Bus fallback in every client method.
