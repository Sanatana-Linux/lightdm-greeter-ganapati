# Conventions — LightDM Greeter Ganapati

## Naming

- Packages: short lowercase nouns — `dbus`, `ui`, `config`, `theme`.
- Exported symbols PascalCase; domain-style interfaces, **no `I` prefix**: `GreeterClient`, `UIActionHandler`.
- Acronyms stay uppercase: `NewLightDMClient`, `UIActionHandler`, `ProtocolConnected`; lowercase in unexported context (`proto`, `greeterAPIVersion`).
- Constants: exported PascalCase (`EventShowPrompt`), unexported camelCase (`greeterMessageConnect`, `pamPromptEchoOff`, `maxServerMessage`).
- Mocks: `MockClient`, `MockHandler`.

## File Organization

- Layered by concern: `pkg/dbus` = transport (client.go / signals.go / protocol.go split by channel type), `pkg/ui` = presentation (window.go + layout.go), `pkg/config` = INI parsing, `pkg/theme` = GTK palette.
- Build-tag split: `//go:build !headless` (window.go/layout.go) vs `//go:build headless` (headless.go) — both redeclare the identical `UIActionHandler`, `Window`, `NewWindow`, `Run`, `SetStatus` (API parity across tags is deliberate; keep both surfaces in sync).
- Tests co-located as internal package (same package, not `_test`).

## Error Handling

- `fmt.Errorf` + `%w` wrapping with lowercase `action: %w` prefixes: `"connect system bus: %w"`, `"call Authenticate: %w"`, `"add match rule: %w"`.
- Graceful degradation over fatal: `Connect()` logs and continues when protocol is live; `GetSessions()` falls back to directory scan, then dummy sessions; `LoadConfig` returns defaults on missing file.
- nil-channel sentinel: `ProtocolEvents()` returns nil when unconnected.
- `os.Exit`/`log.Fatalf` only at the top level (main); packages log via `log.Printf("Greeter protocol: ...")` and return errors.

## Concurrency & Events

- Channels buffered **cap 100**: `make(chan GreeterEvent, 100)` in both `openProtocol()` and `NewSignalListener()`.
- Non-blocking emit: `emit()` uses `select { case p.eventsCh <- ev: default: }` — drops events when the UI stalls.
- Teardown: `closeCh` + `sync.Once` in `protocolConn.stop()`; `SignalListener.Stop()` closes `closeCh`.
- Goroutine ownership explicit: `readLoop` owns `fromServer` reads; `Window.Run` spawns event-router + Gio-window goroutines, then blocks on `app.Main()`.
- `writeMu sync.Mutex` serializes writes to `toServer` in `send()`.

## Testing

- Run with `go test -v -tags headless ./...` (justfile) — tests exercise the headless build (no cgo/graphics needed).
- Table-driven + `t.Run`: `TestMockClientAuthSequence`, `TestParseHex`, `TestParseFunc`.
- Mocks record into exported fields: `MockClient{AuthedUser, LastPass, Canceled, SessStart}`.
- Wire-format golden bytes: `TestWireHelpers` asserts exact BE byte slices.
- Injectable hooks: `searchDirsFn` package var, `os.Setenv("NON_INTERACTIVE")`, `envFD` reads real env.
- Event-drain helper `collect()` + `buildFrame()` in protocol_test.go.

## Protocol/Wire Discipline

- Framing: `[uint32 BE id][uint32 BE length][payload]`; strings `[uint32 BE len][raw bytes]`, no NUL.
- `putU32`/`putString` write; `takeU32`/`takeString` return `(value, ok bool)` and fail closed on truncation.
- `maxServerMessage = 64 * 1024`; `dispatch` returns nil on oversize (fatal framing error). Partial messages buffer between reads.
- Never trust a declared length before bounds-checking.

## Nix Packaging

- Flake outputs: `packages.{default,headless}`, `devShells`, `apps.vm`, `nixosModules.default`, `nixosConfigurations.vm`; `forEachSystem` over x86_64-linux + aarch64-linux.
- Two-output package: `outputs = [ "out" "xgreeters" ]`; `postInstall` writes the `.desktop` into `$out/share/xgreeters` and copies it to `$xgreeters/` so the module can point `greeter.package = ...default.xgreeters`.
- `vendorHash` pinned; `buildHeadless ? false` gates `tags` and graphics `buildInputs` via `lib.optionals (!buildHeadless)`.
- NixOS module options under `greeters.ganapati.{enable,wallpaper,themeName,darkTheme}`; Stylix integration via `config.stylix.image`, `config.gtk.theme.name`, `stylix.polarity`.
