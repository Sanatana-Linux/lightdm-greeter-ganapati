## Architecture Overview

Four-layer Go application (module `github.com/max-moser/lightdm-greeter-ganapati`), packaged as a NixOS flake, replacing slick-greeter as the LightDM greeter.

- **Entrypoint** — `cmd/lightdm-greeter-ganapati/main.go`: `greeterOrchestrator` implements `UIActionHandler` (`OnAuthenticate`/`OnRespond`/`OnCancel`/`OnStartSession`/`OnError`), binding UI events to client methods. Sleeps 1500 ms for display-socket stabilization; `client.Connect()` failure is non-fatal — the UI renders standalone for dev.
- **Transport** — `pkg/dbus`: `protocol.go` implements the LightDM >= 1.31 greeter pipe protocol (`protocolConn`); `client.go` (`GreeterClient` interface, `LightDMClient` struct) dispatches protocol-first with D-Bus fallback + session discovery; `signals.go` (`SignalListener`) maps legacy D-Bus signals to the shared `GreeterEvent` stream.
- **UI** — `pkg/ui`: `window.go` + `layout.go` are the Gio immediate-mode greeter (window explicitly sized to the X screen because the greeter runs with no window manager, cover-fit wallpaper, login card with avatar + session selector); `auth.go` holds the pure `resolveSignIn` decision shared by the Sign In button and the keyboard paths; `screen_x11.go` queries the X screen size.
- **Config** — `pkg/config/config.go`: INI parser for `/etc/lightdm/lightdm-greeter-ganapati.conf` (`[GTK]` theme/dark, `[Greeter]` background/default-session), defaults to Libadwaita-dark.
- **Theme** — `pkg/theme/theme.go`: resolves a named GTK theme (NixOS store paths first), scans `gtk-3.0/gtk.css` for `@define-color` roles, parsing `#RGB`/`#RRGGBB`/`rgb()/rgba()` into a `Palette`.

## Control Flow (auth lifecycle)

1. Username Enter/click → `Window.startAuth` (optimistic: `needPassword=true` immediately) → `OnAuthenticate` → `client.Authenticate` → `sendAuthSequence`: increments `authSeq`, writes `AUTHENTICATE` (id 1) `[seq][username]`.
2. Server replies `PROMPT_AUTHENTICATION` (id 1): `[seq][username][n][{style,text}*n]` — PAM styles 1/2 → `EventShowPrompt`, 3 → error `EventShowMessage`, 4 → info.
3. Password submit → `OnRespond` → `sendResponse`: `CONTINUE_AUTHENTICATION` (id 3) `[n_secrets=1][secret]`.
4. `END_AUTHENTICATION` (id 2) `[seq][username][result]`: non-zero → `EventShowMessage("Authentication failed")` then `EventAuthComplete`; zero → `EventAuthComplete` only.
5. `Window.Run` event router: on `EventAuthComplete`, only when `statusMsg == ""` does it call `OnStartSession(currentSess.ID)` → `sendStartSession` (id 4).
6. `SESSION_RESULT` (id 3): 0 → logged; non-zero → `EventShowMessage("Failed to start session")`.

**Event channel contract** — `GreeterEvent{Type EventType; Text string; Param uint32}`; `EventType`: `EventShowPrompt`/`EventShowMessage`/`EventAuthComplete`/`EventReset`. `Param`: prompt echo type or message severity (0=info, 1=error). `EventReset` (protocol id 6 / D-Bus `Reset`) clears editors + state.

## Concurrency Model

- **Gio main loop** — `app.Main()` on the main thread; `app.Window` goroutine handles `FrameEvent` → `handleActions` + `Render`.
- **Event router goroutine** — spawned per `Run()`, ranges over `events`, mutates `Window` fields directly (single-writer pattern, mirrored by `SetStatus`).
- **Protocol reader goroutine** — `readLoop` chunked-reads `fromServer`, incrementally frames via `dispatch`, capped at `maxServerMessage` 64 KiB.
- **Buffered channels** — `eventsCh` cap 100 (protocol + signal listener); raw D-Bus channel cap 50. `emit` is non-blocking (`select`/`default`, drops on full).
- **Synchronization** — `writeMu` serializes writes to `toServer`; teardown via `done sync.Once` in `stop()` closing `closeCh` + FDs (deferred from `readLoop`).

## Integration Surfaces

- **Pipe protocol (>= 1.31)** — inherited FDs `LIGHTDM_TO_SERVER_FD`/`LIGHTDM_FROM_SERVER_FD`; framing `[uint32 BE id][uint32 BE len][payload]`, strings `[u32 len][bytes]`. Client ids 0–8 (CONNECT, AUTHENTICATE, AUTHENTICATE_AS_GUEST, CONTINUE_AUTHENTICATION, START_SESSION, CANCEL_AUTHENTICATION, SET_LANGUAGE, AUTHENTICATE_REMOTE, ENSURE_SHARED_DIR); server ids 0–7 (CONNECTED, PROMPT_AUTHENTICATION, END_AUTHENTICATION, SESSION_RESULT, SHARED_DIR_RESULT, IDLE, RESET, CONNECTED_V2). CONNECT advertises `greeterAPIVersion=1`, resettable=1.
- **Legacy D-Bus (<= 1.30)** — dest `org.freedesktop.DisplayManager`, seat from `LIGHTDM_GREETER_SEAT_PATH` (default `Seat0`); methods `Seat.Authenticate[AsGuest]/Respond/CancelAuthentication/StartSession`; signals `Seat.ShowPrompt/ShowMessage/AuthenticationComplete/Reset` via `AddMatch` rule.
- **Session discovery** — D-Bus property `Seat.Sessions` + per-session `Id/Name/Type`; fallback: `.desktop` scan of the `sessions-directory` entries from `/etc/lightdm/lightdm.conf` (and `lightdm.conf.d/*.conf`), then `/usr/share`, `/usr/local/share`, `/run/current-system/sw/share` (NixOS sessions live in a store path, so the config is authoritative); deduped by basename; dummy awesome/sway fallback.
- **NixOS module** — `services.xserver.displayManager.lightdm.greeters.ganapati.{enable,wallpaper,themeName,darkTheme}`; sets `greeter.name/package` (pointing at the `xgreeters` output), `greeters.gtk.enable = mkForce false`; renders `/etc/lightdm/lightdm-greeter-ganapati.conf`; inherits Stylix (`config.stylix.image`, `gtk.theme.name`, `stylix.polarity`).
- **QEMU VM** — `nixosConfigurations.vm` (qemu-vm.nix, modesetting driver, Spice port 5900, serial log, `testuser`/`testpassword`, getty autologin nulled).

## Build & Packaging

`default.nix`: `buildGoModule` with locked `vendorHash`; graphics `buildInputs` (X11/Wayland/GL/Vulkan) are unconditional; dual outputs `out` + `xgreeters` (desktop file generated in `postInstall`). Flake: `packages.default`, `apps.vm`, `devShells.default` (go, gopls, pkg-config, golangci-lint + graphics libs, `LD_LIBRARY_PATH` for Vulkan/GL), supported on x86_64/aarch64-linux. Host builds need `--option max-jobs 2` (host `max-jobs = 0`).

## Notable Design Decisions

- **Dual-transport, protocol-first** — `Connect` never fails if the protocol is live; D-Bus degraded to property access. Every auth method checks `proto.connected()` first.
- **Optimistic UI** — password prompt shown before the `PROMPT_AUTHENTICATION` round-trip; `OnError`/`SetStatus` surface async failures.
- **Scoped wallpaper transform** — cover-fit scale/offset pushed via `op.Affine(...).Push` and popped before the clip stack; an unscoped `Add` leaks the transform into input routing, breaking pointer/keyboard hit-testing.
- **Adaptive color handling** — Rec. 709 luminance decides contrast; `shade()` derives secondary surfaces; zero-value NRGBA treated as "theme didn't provide".
