## Domain Language

- **Seat**: Represents a physical collection of input/output hardware (display, keyboard, pointer) forming a workstation.
- **Session**: A graphical desktop environment (Wayland or X11) registered under `/usr/share/xsessions/` or `/usr/share/wayland-sessions/`.
- **Greeter**: The login screen interface spawned by LightDM on a seat to authenticate credentials and launch the chosen session.

## External Services

- **LightDM**: System-wide display manager handling logins, seat activation, and session launching. Communicates via the D-Bus destination `org.freedesktop.DisplayManager`.

## Environment Configuration

This is a system greeter that loads configurations dynamically via:
- `/etc/lightdm/lightdm.conf`
- Local assets and background files defined in custom config structs

## Critical Paths

### User Authentication Flow
1. Connect to LightDM D-Bus
2. Read available sessions and populate the UI dropdown
3. Query the username to initialize `Authenticate(username)`
4. Receive interactive prompts (password, PIN, security tokens) from LightDM and render them in the UI
5. Respond to prompts via `Respond(response)`
6. Listen for `AuthenticationComplete`
7. On successful auth, trigger `StartSession(selectedSessionName)`

## Entry Points

- `cmd/lightdm-greeter-ganapati/main.go` - Command-line binary that connects dependencies and runs the GUI main loop.

## Security Boundaries

- **Authentication**: Isolated in `pkg/dbus/client.go` using D-Bus method invocations. No local parsing of shadow passwords.
