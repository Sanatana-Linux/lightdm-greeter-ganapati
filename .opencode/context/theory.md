## Domain Language

- **Seat** — A physical workstation (display, keyboard, mouse) managed by the display manager; the greeter targets one via `LIGHTDM_GREETER_SEAT_PATH` (default `/org/freedesktop/DisplayManager/Seat0`).
- **Session** — A desktop environment entry (`x11` or `wayland` type) described by a `.desktop` file, offered to the user and passed to `START_SESSION`.
- **Greeter** — The graphical login interface LightDM spawns to collect credentials, validate them, and request session startup.
- **Authentication** — A PAM conversation carried over the protocol, built from prompt/error/info messages with styles `ECHO_OFF` (1, secret input), `ECHO_ON` (2, visible input), `ERROR_MSG` (3, failure text), `TEXT_INFO` (4, informational).
- **Sequence number** — A monotonically increasing uint32 the greeter stamps on `AUTHENTICATE`; the server echoes it in `PROMPT_AUTHENTICATION` and `END_AUTHENTICATION` so responses correlate to attempts.
- **Hints** — The key/value table (default session, autologin user, ...) the daemon echoes in the `CONNECTED`/`CONNECTED_V2` handshake reply; Ganapati currently only logs it.
- **Pipe protocol vs D-Bus API** — LightDM >= 1.31 removed the greeter D-Bus surface and speaks a binary pipe protocol over inherited FDs; <= 1.30 uses the D-Bus `Seat.*` methods and signals. Ganapati prefers the pipe, keeps D-Bus as fallback.

## Event Flow States

CONNECT handshake (`start()` sends version + resettable + API) -> server replies **CONNECTED/CONNECTED_V2** (hints logged; UI idle) -> on submit greeter sends **AUTHENTICATE** (seq n) -> server emits **PROMPT_AUTHENTICATION** (echoes seq; styles map to `EventShowPrompt`/`EventShowMessage`) -> user responds via **CONTINUE_AUTHENTICATION** -> server sends **END_AUTHENTICATION** (`result != 0` surfaces "Authentication failed" before `EventAuthComplete`) -> on success the UI (guarded by no pending status message) fires **START_SESSION** -> server replies **SESSION_RESULT** (0 logged; 1 surfaces "Failed to start session"). **IDLE** (server waiting) is a no-op. **RESET** (daemon echoes hints) emits `EventReset`, clearing in-progress auth state, editors, and status. A failed `END_AUTHENTICATION` also clears the password field so the next attempt starts clean.
