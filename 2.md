# LightDM Greeter Rewrite in Go

## Problem Statement

Need a graphical login manager/greeter that:
- Supports **both X11 and Wayland session selection** (user picks at login)
- Is **not** SDDM (dated aesthetic), GDM (GNOME-only), or greetd (Wayland-native dickery)
- Is **not** Electron/Python/GTK3 bloat (Nody Greeter, Web Greeter, Elephant Greeter all suffer)
- Boots fast, minimal dependencies, matches a tasteful GRUB/Plymouth aesthetic
- X11 session support is **mandatory** (AwesomeWM primary session)

## Key Insight: LightDM + Custom Greeter

LightDM itself handles session selection from both `/usr/share/xsessions/` and `/usr/share/wayland-sessions/`. The greeter is just the visual frontend — it collects credentials and a session choice, then LightDM's seat daemon launches the session. **The greeter's display backend has zero bearing on what session gets launched.**

## Elephant Greeter as Reference

Elephant Greeter (github.com/max-moser/lightdm-greeter-ganapati) ships two modes:
- `lightdm-greeter-ganapati.desktop` — runs under Cage (Wayland compositor)
- `lightdm-greeter-ganapati-x11.desktop` — runs under X11 normally

It's Python/GTK3, ~68 stars, simple UI. The X11 mode works fine for launching X11 sessions.

## The Rewrite: Go

### Why Go
- Compiles to a single static binary — no Python runtime, no GTK3 dependency hell
- Fast startup (compiled, not interpreted)
- LightDM D-Bus interface is well-defined
- Gio (gioui.org) for pure Go GPU-accelerated UI, no toolkit deps
- Or use simpler approach with `andlabs/ui` or raw X11 calls

### LightDM D-Bus Interface

LightDM exposes its greeter API over D-Bus at `org.freedesktop.DisplayManager`:

- **Auth flow**: `Authenticate(session_path, username)` → `Respond(password)` → signals
- **Session list**: Read `GetSessions` property or call `ListSessions`
- **Launch**: `StartSession(session_id)` after successful auth
- **Seat management**: `org.freedesktop.DisplayManager.Seat` interface

Go D-Bus library: `github.com/godbus/dbus/v5`

### Estimated Scope

- **~300-500 lines of Go** for the full greeter
- UI: centered box with username field, password field, session dropdown, login button
- D-Bus integration for LightDM greeter API
- Config file for theming (colors, background, fonts)
- Systemd service file or LightDM greeter `.desktop` file

### Alternative: Gio (gioui.org) for UI

- Pure Go, no C dependencies beyond the basics
- GPU-accelerated rendering
- Cross-platform, but we only need Linux
- Handles text input, buttons, dropdowns natively
- Can do custom drawing for theming
