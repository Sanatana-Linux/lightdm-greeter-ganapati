# Login Managers/Greeters Supporting Wayland & X11 Session Selection

## Research Question

Which login managers (display managers / greeters) support logging into either a Wayland or X11 session, with the user able to select which protocol to use as part of the login process?

---

## Key Findings

All major modern display managers support **both Wayland and X11 sessions** and present them in a session chooser dropdown/menu at login time. The mechanism is standardized: desktop environments and window managers install `.desktop` files into `/usr/share/wayland-sessions/` (for Wayland) and `/usr/share/xsessions/` (for X11), and the display manager reads both directories to populate the session list.

---

## Detailed Comparison

### 1. SDDM (Simple Desktop Display Manager)

| Attribute | Detail |
|-----------|--------|
| **Status** | Active, widely used |
| **Default for** | KDE Plasma (historically), LXQt |
| **Session selection** | ✅ Dropdown menu listing both Wayland and X11 sessions |
| **Wayland support** | Lists Wayland sessions since v0.20; experimental Wayland greeter available |
| **X11 support** | Full, mature |
| **Greeter** | QML-based, highly themeable (Breeze, etc.) |
| **Config** | `/etc/sddm.conf.d/` |
| **Service** | `sddm.service` |
| **Notes** | Default greeter runs in X11 mode; can be switched to experimental Wayland greeter via `DisplayServer=wayland` + `CompositorCommand=kwin_wayland ...`. Reads sessions from both `/usr/share/xsessions/` and `/usr/share/wayland-sessions/`. |

### 2. GDM (GNOME Display Manager)

| Attribute | Detail |
|-----------|--------|
| **Status** | Active, GNOME's official DM |
| **Default for** | GNOME |
| **Session selection** | ✅ Gear/cog icon menu listing available sessions (Wayland & X11) |
| **Wayland support** | Default backend (Wayland); falls back to Xorg if Wayland unavailable |
| **X11 support** | Full, via Xorg backend |
| **Greeter** | GNOME Shell in greeter mode |
| **Config** | `/etc/gdm/custom.conf` + dconf |
| **Service** | `gdm.service` |
| **Notes** | Wayland is the default. To force Xorg: uncomment `WaylandEnable=false` in `custom.conf`. Session list populated from `/usr/share/wayland-sessions/` and `/usr/share/xsessions/`. |

### 3. LightDM

| Attribute | Detail |
|-----------|--------|
| **Status** | Active, lightweight, cross-desktop |
| **Default for** | Ubuntu (historically), Xubuntu, Linux Mint |
| **Session selection** | ✅ Dropdown/selector in greeter (varies by greeter frontend) |
| **Wayland support** | ✅ Supported (greeter runs under X, launches Wayland sessions) |
| **X11 support** | ✅ Full |
| **Greeters** | Multiple: GTK Greeter, Slick Greeter, WebKit2 Greeter, Pantheon Greeter, etc. |
| **Config** | `/etc/lightdm/lightdm.conf` + per-greeter config files |
| **Service** | `lightdm.service` |
| **Notes** | Modular greeter architecture. The greeter itself runs under X11 but can launch Wayland sessions. Session list from both session directories. Slick Greeter (Linux Mint) is particularly polished. |

### 4. greetd (Login Daemon)

| Attribute | Detail |
|-----------|--------|
| **Status** | Active, minimal, compositor-agnostic |
| **Default for** | Sway, Hyprland, other Wayland compositors |
| **Session selection** | ✅ Depends on greeter (most support it) |
| **Wayland support** | ✅ Native (designed for Wayland compositors) |
| **X11 support** | ✅ Supported via greeter configuration |
| **Greeters** | gtkgreet, ReGreet, wlgreet, tuigreet, nwg-hello, qtgreet, ddlm, cosmic-greeter |
| **Config** | `/etc/greetd/config.toml` |
| **Service** | `greetd.service` |
| **Notes** | Not a traditional display manager — a minimal login daemon. Greeters run inside a Wayland compositor (cage, sway, Hyprland). ReGreet and gtkgreet read both `/usr/share/xsessions/` and `/usr/share/wayland-sessions/` for session selection. Very popular in the Wayland-native/WM community. |

### 5. Plasma Login Manager

| Attribute | Detail |
|-----------|--------|
| **Status** | Active, KDE's new DM (forked from SDDM) |
| **Default for** | KDE Plasma 6+ |
| **Session selection** | ✅ Dropdown menu (same as SDDM) |
| **Wayland support** | ✅ Full (KWin Wayland compositor) |
| **X11 support** | ✅ Full |
| **Greeter** | KDE-native, wallpaper plugin integration |
| **Config** | `/etc/plasmalogin.conf` + System Settings KCM |
| **Service** | `plasmalogin.service` |
| **Notes** | Successor to SDDM for KDE Plasma. Reads both session directories. Integrates with Plasma wallpaper plugins. |

### 6. Ly (TUI Display Manager)

| Attribute | Detail |
|-----------|--------|
| **Status** | Active, lightweight TUI |
| **Default for** | Minimalist setups, tiling WM users |
| **Session selection** | ✅ Arrow-key navigable session list |
| **Wayland support** | ✅ Supported |
| **X11 support** | ✅ Supported |

## How Session Selection Works (Standard Mechanism)

All modern display managers use the **freedesktop.org Desktop Entry Specification**:

1. **X11 sessions**: `.desktop` files in `/usr/share/xsessions/`
   - Example: `/usr/share/xsessions/plasma.desktop`, `/usr/share/xsessions/gnome-xorg.desktop`
2. **Wayland sessions**: `.desktop` files in `/usr/share/wayland-sessions/`
   - Example: `/usr/share/wayland-sessions/plasma.desktop`, `/usr/share/wayland-sessions/gnome.desktop`
3. The display manager reads both directories and presents them in a unified session chooser
4. The user selects their desired session (and thus protocol) at login time

## Recommendations by Use Case

| Use Case | Recommended DM | Rationale |
|----------|---------------|-----------|
| **KDE Plasma** | Plasma Login Manager or SDDM | Native integration; session chooser built-in |
| **GNOME** | GDM | Official GNOME DM; Wayland-first |
| **Lightweight / cross-desktop** | LightDM + Slick Greeter | Modular, many greeters, low resource usage |
| **Wayland-native / tiling WMs** | greetd + ReGreet/gtkgreet | Designed for compositors; minimal footprint |
| **Minimalist / TUI** | Ly or tuigreet | No X dependencies; works on any TTY |
| **Server / kiosk** | greetd + agreety | Minimal, scriptable |
